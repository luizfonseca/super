<Warning>
  Daemon mode only works if every path provided is **absolute**. _Any path defined using  `./` won't work as the daemon will not be able to find it since it runs on a different path scope._
</Warning>

## Command

Daemon mode is a mode that allows Super to run as a **background** process.

This is useful for running Super on a server, where you don't want to have to manually start and stop Super every time you want to use it.

To run Super as a daemon, you need to use the `-d` or `--daemon` flag.

For example, to run Super as a daemon, you can use the following command:

```bash
super -d -c /absolute-path-to-config-folder
```
