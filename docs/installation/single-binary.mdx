You can also run Super as a standalone binary using rust's `cargo` or downloading it directly from [https://github.com/luizfonseca/super/releases](https://github.com/luizfonseca/super/releases) for your system.

## Cargo

Super is a Rust-based proxy service and can be installed as a binary through the published version [on crates.io](https://crates.io/crates/proksi).

To install (and compile) Super for your system, first ensure you have the latest Rust version:



### 1. Rust is not installed

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

### 2. Rust is already installed

```bash
rustup update
```

### 3. Install the binary

```bash
cargo install --git https://github.com/luizfonseca/super super_proxy
```

You can now run Super as a user binary:

```bash
touch config.hcl
# add routing configuration to your config.hcl file

super -c ./
```



## Downloading the binary

Download the archive for your system from the [Releases page on GitHub](https://github.com/luizfonseca/super/releases): `super-linux-musl-x86_64`, `super-linux-musl-aarch64` (static, any Linux), `super-linux-gnu-*`, `super-macos-aarch64` or `super-macos-x86_64`. For example:

```bash
# Replace the version and platform with the ones you want
curl -L -O https://github.com/luizfonseca/super/releases/download/super-v0.4.0/super-linux-musl-x86_64.tar.gz
tar -xzf super-linux-musl-x86_64.tar.gz
chmod +x ./proksi
```

Once that is done you can check if the binary is functional:

```
super --help
```
